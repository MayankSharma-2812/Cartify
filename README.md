# Mini E-commerce

This is a simple e-commerce application built using React and Vite. It includes the following features:

* Home page with a list of products
* Product page with product details
* Cart page with a list of products in cart
* Wishlist page with a list of products in wishlist
* Navbar with links to different pages

The application is built using React hooks and React Router for client-side routing. The application is also optimized for performance using Vite's optimization features.

## Installation

1. Clone the repository
2. Install dependencies using `npm install`
3. Start the application using `npm start`

## Features

* Responsive design for different screen sizes
* Client-side routing using React Router
* Optimization using Vite's optimization features
* Use of React hooks for state management
* Use of React icons for icons

## Pages

* Home page: Lists all products
* Product page: Shows product details
* Cart page: Lists all products in cart
* Wishlist page: Lists all products in wishlist

## Components

* Navbar: Includes links to different pages and a cart icon
* Product card: Includes product image, name, price and add to cart button

## Technologies used

* React
* React Router
* React icons
* Vite
